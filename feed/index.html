yuzl1 OpenWrt 软件源

请按固件版本选择对应的源。23.05 用 opkg，25.12 用 apk，两种包格式不能混用。

23.05（opkg / .ipk）

适用于 ImmortalWrt 23.05、OpenWrt 23.05。

https://yuzl1.github.io/openwrt-luci-apps/23.05/

旧地址 https://yuzl1.github.io/openwrt-luci-apps 仍然可用。

25.12（apk / .apk）

适用于 ImmortalWrt 25.12、OpenWrt 25.12（apk 包管理器）。

https://yuzl1.github.io/openwrt-luci-apps/25.12/

查看 APKINDEX

23.05 配置（opkg）

echo "src/gz yuzl1apps https://yuzl1.github.io/openwrt-luci-apps/23.05/" >> /etc/opkg/customfeeds.conf
opkg update
opkg install luci-app-ddns-lite luci-app-tailscale-community tailscale

25.12 配置（apk）

wget -O /etc/apk/keys/yuzl1-apk-25.12.pem https://yuzl1.github.io/openwrt-luci-apps/25.12/yuzl1-apk-25.12.pem
echo "https://yuzl1.github.io/openwrt-luci-apps/25.12/" >> /etc/apk/repositories.d/customfeeds.list
apk update
apk add luci-app-ddns-lite luci-app-tailscale-community tailscale

先安装 yuzl1-apk-25.12.pem 公钥后，源索引和包都带 ECDSA P-256 签名，不需要 --allow-untrusted。如果暂时不想装公钥，也可以直接下载 .apk 用 apk add --allow-untrusted 手动安装。
